# Git Scratch

A simple repository created for practicing **Git and GitHub** workflows.

## About

In this repository, we practice Git commands and workflows while working with **Terraform code**.

The main purpose is to get hands-on experience with:

- Git commands
- Branching and merging
- Commits and commit history
- Pull requests
- GitHub workflows
- Terraform configuration files

## Tech Used

- **Git**
- **GitHub**
- **Terraform**

## Purpose

This is a practice repository, so the code and commits may change frequently as part of the learning process.

Happy Coding! 🚀
